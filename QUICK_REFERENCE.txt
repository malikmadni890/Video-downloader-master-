🚀 DEPLOYMENT IN 3 STEPS
═══════════════════════════════════════════════════════════════════════

STEP 1: GitHub Upload (2 minutes)
────────────────────────────────
1. Create repo: downloader-master-backend
2. Upload all files from this folder
3. Push to GitHub

STEP 2: Railway Deploy (3 minutes)
────────────────────────────────
1. Go to railway.app
2. New Project → Deploy from GitHub
3. Select downloader-master-backend
4. Deploy! ✅
5. Get your Railway URL

STEP 3: Update HTML (1 minute)
────────────────────────────────
1. Open: downloader_master_hybrid.html
2. Line 50: const YOUTUBE_BACKEND='https://YOUR-URL'
3. Replace YOUR-URL with your Railway URL
4. Save!
